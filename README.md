# Maria Shopova: portfolio

Personal portfolio site showcasing Lucid and Ūtil. Built with [Astro](https://astro.build)
and Tailwind CSS v4, adapted from Ryan Fitzgerald's MIT-licensed
[devportfolio](https://github.com/RyanFitzgerald/devportfolio) template (see `LICENSE.md`).

## Licence and content

The template code is MIT-licensed (see `LICENSE.md`). The personal content on

Shopova and all rights are reserved. See [NOTICE.md](NOTICE.md).

## Editing the content

Everything on the page comes from one file: [src/config.ts](src/config.ts).
Name, tagline, bio, skills, projects, and (optionally) experience, education
and social links. Anything left empty is hidden from the page automatically.

## Commands

```bash
npm install
npm run dev       # local preview at http://localhost:4321
npm run build     # production build into dist/
npm run preview   # serve the production build locally
```
